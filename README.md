# Pennywise

A modern finance management platform for tracking personal finances, managing shared expenses, and collaborating with groups.

## Overview

Pennywise is a full-stack finance management application designed to simplify personal budgeting and collaborative expense tracking. It enables users to record transactions, organize finances, and manage shared expenses within groups.

## Repository Structure

```text
.
├── api/    # Spring Boot backend
└── web/    # React frontend
```

## Tech Stack

### Backend

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend

- React
- Vite
- Tailwind CSS

## Features

- Personal income and expense tracking
- Shared group expenses
- Expense settlements
- Budget management
- Transaction history
- Secure authentication
- Financial insights
